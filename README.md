# DZ1

## Описание

Данный проект представляет из себя мою реализацию первого домашнего задания на курсе OTUS ***"Высоконагруженные системы: архитектура и масштабирование"***

## Статус проекта

Реализованы методы:

- `/login`
- `/user/register`
- `/user/get/{id}`
- `/user/search?first_name=<Имя>&last_name=<Фамилия>`

## Запуск проекта

### Требования

- Docker Engine
- Docker Compose V2 (`docker compose`)

### 1. Настройка окружения

Перед запуском необходимо создать и заполнить все `.env`-файлы, используемые для настройки БД и приложения.

```bash
cp .env.example .env
openssl rand -hex 32 
### скопировать вывод, он понадобиться для настройки токенов авторизации

vi .env
### Заполнить переменную JWT_SECRET сгенерированным секретом
### Заполнить пароль админа базы данных

cp config/db-app.env.example config/db-app.env
vi config/db-app.env
### Заполнить пароль с которым приложение будет подключаться к БД
```

### 2. Сборка и запуск

Из корневой директории проекта выполните:

```bash
docker compose up -d --build
```

Команда соберёт образы приложения, создаст необходимые сети и тома, запустит PostgreSQL, выполнит инициализацию БД через `db-init` и запустит Go-приложение.

### 3. Проверка работы

Посмотреть состояние контейнеров:

```bash
docker compose ps -a
### Должно быть 3 контейнера
# NAME              ...     STATUS      ...
# dz1-app-1         ...     UP          ...
# dz1-db-init-1     ...     Exited (0)  ...
# dz1-postgres-1    ...     UP          ...
```

Контейнер `db-init` используется только при старте БД для её настройки - проведения миграций описанных в `db/migrations`, как только настройка завершена, контейнер завершает свою работу

Посмотреть логи приложения:

```bash
docker compose logs -f app
```

Приложение доступно по адресу:

`http://localhost:8080`

### 4. Остановка

Остановить и удалить контейнеры проекта:

```bash
docker compose down

### Для удаления контейнеров вместе с томами (включая данные PostgreSQL):
docker compose down -v
```
